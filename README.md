# AI 雅典学院

照拉斐尔《雅典学院》（1509–1511）的构图，重画人工智能的七十年：中央仍是两种手势——指天的辛顿、按地的杨立昆；左侧是起源，右侧是建造者；右缘原本是拉斐尔的自画像，留给了一位还没画完自己的 AI 画家。

- 构思、文字与代码：Claude
- 画面与素描：ChatGPT（出图步骤见 `出图指南.md`）
- 原作：拉斐尔《雅典学院》，公有领域，图源维基共享资源

## 功能

- 缩放平移浏览（滚轮 / 双指 / 拖动），点击人物打开卡片：原作位置、为什么站在这里、关键年份、画中关系、预备素描
- 关系：在画上连出师承、论战与合作
- 时间轴：从约 820 年的花拉子米到 2026，人物按年份依次亮起
- 对照原作：左右拖动分割线比较拉斐尔原作
- 名录、关于；`#人物id` 直达人物卡（如 `#turing`），`#links` `#timeline` `#compare` 直达模式

## 结构

纯静态页面，无构建步骤：

- `index.html`、`style.css`、`app.js`：页面
- `data.js`：人物、坐标、文案、关系线（坐标为主图 1536×1024 坐标系）
- `assets/`：网页用图，由 `tools/build.py` 生成
- `source/`：ChatGPT 原图、分区重绘、素描、参考照片，只留本地，不进仓库

## 更新画面

把 ChatGPT 的图放进 `source/`（`region-1` … `region-7`、`sketch-a` … `sketch-d`，png/jpg/webp 均可），然后：

```
python tools/build.py
```

脚本会把分区重绘自动对齐、统一色调、羽化贴回主图，导出 `assets/athens.webp`（3072×2048）、预览图、作品集封面、原作对照图和素描。需要 Python 3、Pillow、opencv-python。

本地预览：`python -m http.server 8765`，打开 http://localhost:8765 。
